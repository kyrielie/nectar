AO3's own dark skin. Light grey text on a dark grey page, white links that fade to grey once visited, a blue accent for emphasis, and Georgia for the title and headings over a Lucida Grande / Verdana body. There is no header block above the title.

Source: the Reversi skin that ships with the Archive of Our Own software, [otwcode/otwarchive](https://github.com/otwcode/otwarchive). This bundle reimplements an AO3 default skin, so it is covered by the same license as the archive software, the GNU General Public License, version 2 ([GPL-2.0](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html)). The CSS was written by hand for Nectar's template; it does not use code or colors from ReversiPlusPlus.

No third-party fonts or assets; the font stacks name fonts already on the device.
