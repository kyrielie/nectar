# Pen Margins

A pencil-and-notebook page: every frame is a 2px line drawn with elliptical corner radii so each side bows like a pen stroke, headings are handwriting, and links carry a hand-drawn underline. Pink accent; ghost white or charcoal paper.

Original design for Nectar. Inspired by *Doodling 3x1* by *palemomos (Themes by Pale)*. It was read for technique and palette only; the layout, the copy, the names and every drawn shape are new and written from scratch as plain CSS (no code, images, icons or fonts from the source). The source's published terms forbid copying its code or recreating it elsewhere, so this is a different design: it shares no markup, names, code or art, and only uses general techniques.
