# Strip Credits

A credits-page look: a narrow column with hard color inversion, so every heading is a full-width strip in the opposite color, split rows put the label left and the value right, and links fade slowly. White on charcoal at night; charcoal on white by day, mustard accent.

Original design for Nectar. Inspired by *your bones* by *octomoosey*. It was read for technique and palette only; the layout, the copy, the names and every drawn shape are new and written from scratch as plain CSS (no code, images, icons or fonts from the source).
