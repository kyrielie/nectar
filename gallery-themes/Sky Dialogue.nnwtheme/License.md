# Sky Dialogue

A role-playing dialogue window under a tiled pixel sky: double-line borders, a blinking block cursor after the byline, and star-speckled backgrounds drawn with gradients. Retro purple at night; pastel lilac by day.

Original design for Nectar. Inspired by *See The Stars With Me* by *palemomos (Themes by Pale)*. It was read for technique and palette only; the layout, the copy, the names and every drawn shape are new and written from scratch as plain CSS (no code, images, icons or fonts from the source). The source's published terms forbid copying its code or recreating it elsewhere, so this is a different design: it shares no markup, names, code or art, and only uses general techniques.

## Third-party assets
