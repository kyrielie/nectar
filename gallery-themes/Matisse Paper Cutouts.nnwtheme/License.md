# Matisse Paper Cutouts

Original design for Nectar, inspired by the 'Matisse Paper Cutouts' look; set in Libre Caslon Text, Lora, Outfit via Google Fonts (SIL OFL / Apache 2.0).

The layout, type and CSS are original (see License below). The coral-shaped
cutouts in the header and the chapter divider are adapted from the vector
illustration "Flat design Matisse style illustration" (files 7601262 / 7601263 /
7601264) supplied for this project. Those shapes are third-party artwork: they
are NOT covered by the CC0 dedication below and stay under the license of the
original illustration. Check that license (attribution terms in particular)
before publishing this theme.

Fonts: Libre Caslon Text, Lora and Outfit, served from Google Fonts (SIL OFL).
