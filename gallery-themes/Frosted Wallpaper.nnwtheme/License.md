# Frosted Wallpaper

Frosted-glass panels over a soft gradient wallpaper: panels blur a little more and flood with accent when touched, and the title is a pink-to-blue text gradient. Pastel pink and blue by day; charcoal glass at night.

Original design for Nectar. Inspired by *Glazed* by *palemomos (Themes by Pale)*. It was read for technique and palette only; the layout, the copy, the names and every drawn shape are new and written from scratch as plain CSS (no code, images, icons or fonts from the source). The source's published terms forbid copying its code or recreating it elsewhere, so this is a different design: it shares no markup, names, code or art, and only uses general techniques.

## Third-party assets

Fonts are not bundled; they load from Google Fonts at read time and keep their own licenses (Nanum Gothic Coding, Sandoll Communication, SIL OFL 1.1).
