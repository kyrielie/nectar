1-Bit Desktop is a mockup-derived theme: background var(--w), text var(--k), accent var(--k), headings in Pixelify Sans over body text in IBM Plex Sans, with a dark-mode palette.

Source: designed as a CSS mockup for Nectar (Batch 3) and converted to this bundle by script. License: not yet decided; set one before publishing.

Fonts: loaded from Google Fonts by `@import` (IBM Plex Sans, Pixelify Sans). Per-family licenses were not checked.
