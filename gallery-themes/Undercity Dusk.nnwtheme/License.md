# Undercity Dusk

Original design for Nectar. Light mode: an arched brass cartouche with riveted plates; dark mode: hazard stripes and chamfered readouts. Set in Playfair Display SC, Source Serif 4, Oswald and JetBrains Mono via Google Fonts (SIL OFL).
