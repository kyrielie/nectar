# Bundles meant to stay portable to upstream NetNewsWire. CI (the `upstream-compat`
# job in .github/workflows/ci.yml) runs `nnw-theme check` on every name below and
# fails if one fails. One bundle name (the folder name without .nnwtheme) per line;
# blank lines and lines starting with '#' are ignored. Run it locally with
#   python3 gallery/upstream_compat.py
# See docs/theme-gallery.md, "Upstream-compatibility gate".
#
# A bundle belongs here only if it also meets the upstream rules Nectar does not
# otherwise enforce: no @import (themes that use one are Nectar-only),
# Info.plist Name equal to the bundle name, no bundle-local url().
