Nectar Themes

for book nerds and color lovers

Additional themes for Nectar. Customize your reading experience using these premade themes inspired by existing AO3 skins, fandoms, and historical typesetting. Nectar is compatible with any NetNewsWire theme. You can also make your own theme! Read the theme docs in the github repository.

Install opens Nectar and automatically installs the theme. AO3 site skins must be modified to be used with Nectar.
