# Local development references

Machine-specific checkout paths, external reference repositories, and personal
tooling notes do not belong in shared project documentation. Keep those notes in
the gitignored `CLAUDE.local.md` file at the repository root.

Durable implementation behavior belongs in the relevant tracked topic document
in this directory. Temporary plans belong in the gitignored `plans/` directory;
move completed plans to `plans/finished/`. See `roadmap.md` for the shared
project direction.
