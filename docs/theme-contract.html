Nectar theme contract

Every rule a .nnwtheme bundle is held to, and who enforces it. Source: docs/nnwtheme-format.md, "Theme contract".

Who checks it

Imported by a personOnly the app loader runs. It is lenient: a missing Info.plist key decodes to an empty value or 0.
Shipped in Themes/ or the galleryEvery level applies: app, build, test, release, plus the docs-only rules authors are trusted to follow.

Path of a change

Edit bundle→Tests (CI)→Gallery build→Release check vs base branch→On a device: docs-only rules

Filter by enforcement

The bundle

Version rule. Start at 1. Raise it whenever stylesheet.css or template.html changes in a bundle that already exists on the base branch. Edits to Info.plist or License.md alone need no bump.
